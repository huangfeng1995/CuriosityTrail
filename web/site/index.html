不是一把万能的 AI 键。五个角色各有各的脾气和分工—— 该发散的让它发散，该较真的让它较真。

貳

两个通道，各管一摊

同一个 AI，同一条链路，区别只在它手上拿多少资料。 改一句话别惊动整本书；重写整章也别只给一句话。

行内

一个选区

选中文字，上方浮出工具条。

  • 改写换一种表达，意思不变
  • 扩写补细节与描写
  • 缩写精简，保留要点
  • 换语气正式 / 口语 / 冷峻 / 悬疑
  • 续写接住这一句往下写
  • 找茬审稿人视角挑毛病

它看到的是：选中的那句 + 前后几句 + 相关人物卡 + 设定

侧边栏

整章 / 整部

宏观的事，交给能看全书的角色。

  • 重写整章按大纲重新组织
  • 生成大纲接上一章的结尾往下排
  • 梳理人物理清关系网与成长弧
  • 查资料站内 + 联网，带来源
  • 一致性设定冲突逐条列出
  • 要灵感从速记本里长出情节

它看到的是：整本大纲 + 当前章全文 + 全部人物卡与设定 + 查到的资料

叁

你的资料，AI 自己去翻

把手记、书摘、网页和 PDF 丢进素材库。AI 会主动去搜， 而且每一条引用都指得回原文的第几页。

  1. 入库PDF 自动解析正文，按页打点
  2. 切词中文按两字一组建索引，不引分词库
  3. 检索站内全文命中，联网搜索补缺
  4. 溯源角标点开，跳回原文并高亮

没有来源的，AI 会直说没有——不拿编的充数。

肆

写到第两百章，靠的不是记性

长篇真正的敌人是失控：设定崩了、伏笔忘了、进度不明。 这些交给机器盯着，你只管写。

一致性检查

规则层先跑一遍，再交给 AI 逐条核。

  • 高第四章称伞为红，前文是黑伞
  • 中门铃在雨夜不该响
  • 低时间线比第一章晚了两小时
