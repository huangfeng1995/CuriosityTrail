寻迹 · 使用说明
================================================

【一、第一次使用】

1. 把收到的压缩包解压到本地磁盘（不要放在压缩包里直接用）。
   推荐放在：C:\寻迹
   整个「寻迹」文件夹就是你的工作目录，别单独挪里面的文件。

2. 双击「启动寻迹.cmd」。

3. 第一次会自动下载运行环境并安装组件，需要联网，大约 2-4 分钟。
   黑色的窗口里会显示进度，请不要关掉它。

4. 等到窗口提示「已启动，正在打开浏览器」，浏览器会自动打开。
   如果没自动打开，手动访问：http://127.0.0.1:3001

5. 首次登录会显示一个密码。它在 app\web\.env 文件里，
   格式是 APP_PASSWORD=后面那串字符。
   登录时勾选「记住我」，以后就不用再输了。

   想改成自己好记的密码：用记事本打开 app\web\.env，
   把 APP_PASSWORD=后面改成你要的密码，保存，重启一下即可。


【二、每天怎么用】

  双击「启动寻迹.cmd」    → 打开浏览器开始写
  写完关掉黑色窗口        → 服务就停了（数据不会丢）
  或者双击「停止寻迹.cmd」 → 停止服务

注意：写作过程中不要关掉那个黑色窗口，关了服务就断了。


【三、AI 写作功能（重要）】

现在还没有配 AI 密钥，所以只能当普通的 Word 用（自己打字编辑）。

要用 AI 帮你写，需要做一步：

  用记事本打开 app\web\.env，找到这一行：

    DEEPSEEK_API_KEY=

  在等号后面填上你的密钥，例如：

    DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx

  密钥申请地址：https://platform.deepseek.com
  （注册后创建 API key，复制那串 sk- 开头的字符）

  填好保存，重新双击「启动寻迹.cmd」即可。

AI 按用量收费，写小说一个月大概几元到几十元，取决于你用它写多少。


【四、数据存在哪 / 怎么备份】

  全部数据在这个文件夹里：
    寻迹\data\curiosity.db   ← 你的小说、章节、人物卡
    寻迹\data\uploads\      ← 上传的图片
    寻迹\data\backups\      ← 每天凌晨 3 点自动备份，保留 7 份

  备份最简单的方法：把整个「寻迹」文件夹复制一份到 U 盘或网盘。

  另外，登录后进「设置 → 备份」，可以随时点「下载完整备份」，
  会存成一个 zip 文件到你的下载目录。

  重要：不要把「寻迹」文件夹放在桌面、下载目录、微信接收文件目录，
  这些地方容易被清理。


【五、遇到问题】

  窗口提示「服务没能启动」
    → 看窗口里打印的日志，一般是网络问题（第一次下载组件失败）。
      换个网络重试，或者确认电脑能上网。

  浏览器打不开
    → 确认黑色窗口还在（没有报错、还在显示内容）。
      然后手动访问 http://127.0.0.1:3001

  忘记密码了
    → 打开 app\web\.env 找 APP_PASSWORD=后面那串。
      真的找不到了，就改成新的任意密码，保存重启。

  想换台电脑用
    → 把整个「寻迹」文件夹拷过去就行，数据一起带走。

  杀毒软件报警
    → 说明一下：这是把服务跑在你电脑本地的程序，不联网偷东西，
      唯一的对外连接是调用 AI 接口。可以在杀毒软件里加白名单。
